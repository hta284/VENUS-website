# CocoVenus - Modern Design System

## Target
Premium beauty e-commerce landing page for CocoVenus - High-converting, modern, feminine yet professional

## Pattern
Hero-Centric + Social Proof + Product Showcase

## Style
Soft UI Evolution + Modern Glassmorphism

## Color Palette
- Primary: #FF6B9D (Modern Coral Pink)
- Secondary: #A8D5BA (Soft Green)
- Tertiary: #8B7B8F (Elegant Purple)
- Accent: #FFD700 (Warm Gold)
- Background: #FAFAFA (Off-white)
- Surface: #FFFFFF (Pure white)
- Text Primary: #1A1A1A
- Text Secondary: #666666
- Border: #E5E5E5

## Key Effects
- Transitions: 300ms for all interactions
- Soft shadows with glassmorphism
- Hover states with smooth upward translation
- Motion-driven interactions
